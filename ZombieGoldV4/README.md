# 断线公路 · 17 号车队（V4.1 交互修正版）

本次小修：车门按钮保持稳定并增加常驻点击引导；地图左上恢复「实验室」，可一键解锁全部五关、开关音乐/震动、进入调参台；蓝色控件和数字门改为橄榄绿与旧金色。

当前试玩：http://127.0.0.1:8024/ 。独立于 V1、V2、V3，保留 inbox 原件，没有推送 GitHub。

从公路求救开始，接回阿岚与乘客，再去诊所找药、荒地取油、谷仓接修理工，最后恢复广播。五关用于讨论玩家体验和美术方向，并非完整商业版本。

## 启动与操作

无需安装 npm 依赖。在本目录运行 `python3 -m http.server 8024 --bind 127.0.0.1`，打开上述网址。也可在上一级双击「启动试玩.command」，选择 V4。需要联网加载固定版本 Three.js 和可选网络字体。

左右拖动或 A/D、方向键控制队伍，自动开火。到求救地点后，可先清门口的感染者再搜索，也可冒险破门：时间更长并引来额外感染者。救出居民后仍要完成护送。

可选地点允许提前接应，或者继续搜索高价值物资并承担警报、尸群与后续大怪风险。接应的最后 2.2 秒仍会战斗，可以移动掩护。包扎每局一次，只能恢复受伤的战斗队员。

## 金币与存档

- 战斗击杀、获救居民均不直接换钱；五关酬金分别为 150、180、210、240、300 金，仅成功接应到账。
- 每局随身包 6 格。任务物资交给车队，纪念物进入故事记录；可交易物品成功撤离后进入安全仓库，出售才变金币。
- 失败或放弃会丢失本局随身物资。已入库物资、金币、装备保留。刷新页面也不会保存进行中的背包。
- 扩容弹匣 450 金：射速 +20%；改良枪管 950 金：伤害 +25%；防护背心 750 金：每局一层护盾。永久拥有，下一次出发应用。
- 存档在本机浏览器 localStorage：`zombie-gold-journey-v4`。编辑器和试玩统计也用独立 V4 键。不同端口/浏览器不共享；没有云存档。

## 工程与验证

- `src/content/journey.js`：五关、人物对白、任务、物品和装备。
- `src/sim/journeysim.js`：停靠搜索、冒险破门、警报引敌。沿用 runsim 的真实子弹、碰撞与伤害。
- `src/journey/controller.js`、`economy.js`：车队流程、背包、仓库、交易、装备和结算。
- `src/view/journeyart.js`、`journeyworld.js`、`mapview.js`：共用 3D 地标、五处环境、公路地图、开门/救援/广播表现。
- `src/ui/missionui.js`：地图标记与归队报告。主流程无捕鱼和赌场关尾入口。
- `src/game.js`：接入原有射击、打击特效、音效和振动。

运行 `sh tests/run.sh`。真实浏览器证据位于上一级 `verification/zombiegold-v4/`。五关不是只调用结算：测试通过真实搜索、战斗和接应流程。

当前策划与参考依据见 `docs/策划案.md`；工程接口见 `docs/工程说明.md`。继承的历史设计存档在 `docs/archive/`，旧捕鱼/避难所模块留在源码中供后续使用，不代表本版启用。

美术现阶段是现有 Spine、GLB 与新场景几何的可玩灰盒表现，尚非最终美术；没有配音、多人、PvP、大地图自由探索或物理涌现系统。原算数门暂留作火力成长验证，题材化表达仍值得下一轮单独讨论。配乐现用 Kevin MacLeod 的《Lightless Dawn》80 秒现成片段，供氛围试听，不生成新音乐。来源与署名见 assets/audio/MUSIC_LICENSE.txt，游戏内实验室也可查看。原 10.23 音乐文件保留，未覆盖。
