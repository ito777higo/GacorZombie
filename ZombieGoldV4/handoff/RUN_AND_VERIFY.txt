ZombieGold V4.1 原工程交接（2026-10-26）

本次仅发布。原始玩法、美术、动画和音乐字节不变。所有变动仅在临时发布副本中完成。
仓库的根 README、贪吃蛇文件和既有 handoff 指令保持原样；本目录已有 README 也原样保留。
旧 README 关于 CDN 的描述已由本次依赖本地化替代：Three.js 0.160.0、原字体及许可均在 vendor。
依赖的下载地址、版本、SHA-256 见 DEPENDENCIES.json。无需 npm install，运行无外网依赖。

从仓库根启动：
  cd ZombieGoldV4
  python3 -m http.server 8028 --bind 127.0.0.1
  浏览器打开 http://127.0.0.1:8028/
必须用 HTTP，不能双击 file://。请用当前 Chrome/Edge，支持 WebGL 和 ES modules。
首次点击开始后音频解锁；音量、存档存在该浏览器同源 localStorage，不会跟 Git 搬到主力机。

源码/素材校验（Python 3.9+）：
  python3 handoff/verify-manifest.py
SHA 清单覆盖当前源码、全部原始 assets、vendor、配置、文档、工具和测试；排除整个 handoff 状态/证据目录与缓存/旧发布包。
因此 SOURCE_MANIFEST 不自包含，不会因主力机后续更新 STATUS 而失效。

现有逻辑测试（建议 Node.js 22.12+，macOS 无 Node 可回落 JavaScriptCore）：
  sh tests/run.sh
本次发布副本执行 8 组 642 项全部通过。含旧 fishsim 回归，不代表新增捕鱼内容。

实际浏览器输入检查（仅测试需 Playwright；游戏运行不依赖它）：
  在仓库外临时目录安装 Playwright，或使用已有安装；不要把 node_modules 提交进仓库。
  PLAYWRIGHT_MODULE=/path/to/node_modules/playwright node handoff/verify-browser.cjs http://127.0.0.1:8028/ /tmp/zombiegold-browser-evidence
默认使用本机 Chrome；CHROME_CHANNEL=chromium 可使用已安装的 Playwright Chromium。
默认屏蔽全部外部 HTTP 请求，使用全新隔离 context/localStorage。
