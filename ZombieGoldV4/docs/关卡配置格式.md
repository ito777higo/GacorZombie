# 关卡配置格式（gatefish-level/1）

一关就是一份 JSON：开局、积木序列、Boss、结尾、剧本金额。demo 的调参台导入、导出用的就是这个格式，自动验关、AI 出关也用它。也可以给 Cocos 团队定自己的配置格式时做参考：字段可以改名，但这几块内容和保存检查的规则建议保留。

格式由 `src/edit/schema.js` 定义（`TOKENS`、`validate()`），跑关逻辑在 `src/sim/runsim.js` 的 `layout()` 里读这些积木。

## 一关的结构

```json
{
  "format": "gatefish-level/1",
  "code": "2-1",
  "ch": 1,
  "title": "打怪掉金币",
  "learn": "结算页「学会了」那一句",
  "hint": "关卡卡片上的一句提示",
  "run": {
    "startN": 8,
    "stand": false,
    "drift": 6,
    "seq": [ ["g", "+10", "x2", { "post": true }], ["w", 4, 6], ["roll", "gun", 1, 120, "C"] ]
  },
  "finale": {
    "boss": { "model": "mech", "name": "机甲", "hp": 2000, "m": 150, "sec": 7, "slam": 2.6, "bite": 4 },
    "after": "rainbow"
  },
  "coins": 700000,
  "par": 1800
}
```

| 字段 | 必填 | 含义 | 取值 |
|---|---|---|---|
| `format` | 建议 | 格式版本 | `"gatefish-level/1"` |
| `code` | 是 | 关卡编号。和 13 关之一相同就是改那一关，不同就是新关卡 | 如 `"2-1"`、`"T-1"` |
| `ch` | 是 | 大关 | 0 = 大关一 数字门，1 = 大关二 兵变金币，2 = 大关三 大鱼爆分，3 = 大关四 捕鱼技能 |
| `title` | 是 | 关卡名 | 文字 |
| `learn` `hint` | 否 | 结算页「学会了」、关卡卡片的提示 | 文字 |
| `run.startN` | 是 | 开局兵数。大关二起实际兵数再 × 兵力系数（全局，现在 ×2） | 1～999 |
| `run.stand` | 否 | 站桩关：队伍不动，积木往脸上飘 | `true` / 不写 |
| `run.drift` | 站桩关必填 | 积木飘过来的速度 | 1～20（demo 用 6～7） |
| `run.seq` | 是 | 积木序列，从前往后排，相邻两项默认间距 26（约 3 秒，全局「积木间距」） | 见下一节 |
| `finale.boss` | 否 | Boss，不写就没有 Boss | 见「Boss」 |
| `finale.after` | 否 | Boss 之后的结尾，不写就直接结算 | 见「结尾」 |
| `coins` | 否 | 剧本金额：一星这关大概给多少金币（一般走法） | 大关二起才能有 |
| `par` | 否 | 一般兵数：一般走法带到结尾的兵 × 倍数跑道倍数，用来算表现系数 | 自动验关「一般」那一行的带回兵数 |

另外几个可选字段，一般不用动：`gift`（拿到技能时指挥官说的话）、`bonus`（鱼池结尾的配置）、`challenge: true`（挑战关标记）、`magic: true`（第 13 关魔术师）、`teachLine` / `teachTide` / `teachEscape` / `teachDodge` / `teachShield` / `teachKills` / `teachBonus`（技能关和大关二的一句话教学）。关卡的定格教学步骤（`teach`）带函数，不进配置，留在代码里。

### 一星怎么定价

打怪、Boss、兑换门照实赔；结尾（彩虹滚轮、金砖墙、黄金雪怪……）的筹码按剧本定价，让这关总共落在「剧本金额 × 表现系数」。表现系数 = 0.3 + 0.7 × 带回兵数 ÷ 一般兵数，夹在 0.6～1.15 之间（全局可调）。所以有剧本金额的关，结尾一定要能出金币。

## 积木

每个积木是一个数组：`[种类, 参数1, 参数2, ..., {选项}]`。选项对象可以不写。

### 门

| 积木 | 写法 | 参数 | 例子 |
|---|---|---|---|
| `g` 门 | `["g", 值1, 值2, (值3), {选项}]` | 一排 2～3 扇。选项：`post` 中间金柱可骑（两扇都吃，先加后乘，撞掉 15%）；`wall` 中间是隔墙；`shoot` 能不能开枪涨数（不写 = 大关二起有加法门就能）；`gap` 到下一项的距离 | `["g", "+10", "x2", {"post": true}]`、`["g", "x10", "+50", {"wall": true}]`、`["g", "S:double", "S:spread", "S:pierce", {"post": true}]` |

门的值：

| 写法 | 意思 |
|---|---|
| `+N` / `-N` | 加兵 / 扣兵（大关二起 × 兵力系数） |
| `xN` | 兵数 × N（×5 起是金色门） |
| `/N` | 兵数 ÷ N（向上取整） |
| `?` | 神秘门：×3 / ×2 / +30 / ÷2 / −25 里按权重随机 |
| `~a,b,c` | 轮盘门：每 0.5 秒换一个值，如 `~x2,+50,/2` |
| `S:技能` | 技能门：`S:double` 双线、`S:spread` 散射、`S:pierce` 穿透、`S:aim` 瞄准、`S:lucky` 幸运 |

### 敌人

| 积木 | 写法 | 参数（取值范围） | 例子 |
|---|---|---|---|
| `w` 怪潮 | `["w", 只数, 血量, {选项}]` | 只数 1～200、血量 1～20000（实际 × 全局数量系数 1.5、血量系数 1.15）。选项：`brute` 带一个精英（最后一只，血 ×9，撞上扣 8 兵）；`power` 每只撞上扣几个兵（默认 1） | `["w", 8, 12, {"brute": 1}]` |
| `ambush` 两侧扑出 | `["ambush", 只数, 血量]` | 队伍靠近时从路两边扑出来的狗 | `["ambush", 12, 11]` |
| `line` 纵队 | `["line", 几路, 每路几只, 血量, {power}]` | 1～6 路、每路 1～12 只，前后紧挨着；普通箭只打到每列最前面那只，穿透一箭打穿一列 | `["line", 4, 6, 20]` |
| `shield` 盾墙 | `["shield", 几个, 血量]` | 一排举盾兵，普通箭只打得动一点，穿透能打穿 | `["shield", 7, 45]` |
| `mb` 小 Boss | `["mb", 血量, 20, 名字, {选项}]` | 第三个数是保留位（写 20）。走到队伍面前撞掉 25%。选项：`escape` 几秒打不倒就背着金子跑（双线教学）；`dodgy` 会横移、闪现（瞄准教学） | `["mb", 900, 20, "运钞怪", {"escape": 6}]` |

### 桶和道具

桶写成三元组 `[种类, 值, 要打几下]`：

| 种类 | 值的意思 |
|---|---|
| `men` 加兵 | 兵数（× 兵力系数） |
| `gun` 换弩 | 升几级（一般 1） |
| `rate` 射速 | 不用，写 1 |
| `coin` 金币堆 | 倍数（× 炮倍） |
| `fish` 鱼牌 | 鱼的名字，如 `hudie` 蝴蝶鱼 ×10、`wugui` 乌龟 ×15、`jianyu` 剑鱼 ×40、`denglong` 灯笼鱼 ×50（见 `src/content/levels.js` 的 `FISH`） |
| `skill` 技能 | `double` / `spread` / `pierce` / `aim` / `lucky` |
| `shield` 护盾 | 层数 |
| `heal` 治疗 | 至少救回几个兵（实际救回刚掉的兵的一半） |

| 积木 | 写法 | 例子 |
|---|---|---|
| `b` 木桶 | `["b", 种类, 值, 要打几下, 位置]`，位置 `L` / `C` / `R` | `["b", "gun", 1, 60, "C"]` |
| `row` 一排三个桶 | `["row", 桶, 桶, 桶]`，某个位置不放写 `null` | `["row", ["men", 4, 3], ["gun", 1, 5], ["men", 4, 3]]` |
| `bb` 左右两个桶 | `["bb", 桶, 桶]` | `["bb", ["men", 10, 20], ["gun", 1, 20]]` |
| `roll` 滚桶 | `["roll", 种类, 值, 要打几下, 位置, {speed}]`，滚过来压兵，打爆拿道具 | `["roll", "gun", 1, 120, "C"]` |
| `roll2` 二选一滚桶 | `["roll2", 桶, 桶, {speed}]`，火力只够打爆一个就二选一 | `["roll2", ["shield", 1, 450], ["men", 40, 450]]` |
| `cage` 笼子 | `["cage", 兵数, 要打几下, 位置]` | `["cage", 10, 30, "C"]` |

### 路上和陷阱

| 积木 | 写法 | 说明 |
|---|---|---|
| `drop` 兵雨 | `["drop", 兵数]` | 直升机空投（× 兵力系数） |
| `f` 跳鱼 | `["f", 条数, {tide, type}]` | 金鱼跳过路面；`tide: true` 是飞鱼潮（一大群挨着，散射教学）；`type` 换鱼 |
| `roller` 滚筒 | `["roller", 位置]` | 压过半边路 |
| `rollers` 两个滚筒 | `["rollers"]` | 左、右各一个 |
| `saw` 电锯 | `["saw", 摆幅, 速度]` | 左右摆，demo 用 `["saw", 3.3, 1.6]` |
| `hole` 破洞 | `["hole", 位置, 长度]` | |
| `wave` 大浪 | `["wave", 位置]` | |
| `split` 分道墙 | `["split", 长度]` | 中间一道墙，选一边走到底 |
| `gap` 空档 | `["gap", 距离]` | 多空出一段（8.5 ≈ 1 秒） |

`coins`（路上金币）和 `br`（旧精英）还能读，但已经不用了（需求案 V2.2 去掉了路上金币）。

## Boss（`finale.boss`）

| 字段 | 含义 | 例子 |
|---|---|---|
| `model` | 模型：`chubby` 巨尸、`yeti` 雪怪、`demon` 恶魔、`mech` 机甲、`kraken` 章鱼触角（五根从水里冒出来）、`magician` 海豹魔术师 | `"mech"` |
| `name` | 血条上的名字 | `"机甲"` |
| `hp` | 血量。实际按队伍火力夹在「战斗时长」的 1～2.2 倍之间 | 2000 |
| `m` | 倍数，打倒赔 ×N 炮倍（大关二起） | 150 |
| `sec` | 战斗时长（秒） | 7 |
| `slam` | 出招间隔（秒），不写就不出招；招式顺序按模型（`src/sim/runsim.js` 的 `BOSS_MOVES`） | 2.6 |
| `bite` | 贴身时每秒啃掉几个兵 | 4 |
| `big` | 大体型 | `true` |
| `escape` | 几秒打不倒就背着金子跑（双线关） | 12 |
| `dodgy` | 会闪，只有瞄准追得上（魔术师） | `true` |
| `shieldWall` | 身前一排盾墙，几个 | 8 |

## 结尾（`finale.after`）

| 值 | 结尾 | 出金币 |
|---|---|---|
| 不写 | 直接结算 | 否 |
| `exchange` | 兑换门（1 兵 = 100） | 照实赔，不按剧本 |
| `rainbow` | 彩虹滚轮 | 是 |
| `bricks` | 金砖墙 | 是 |
| `goldmob` | 黄金雪怪 | 是 |
| `fishleap` | 鱼跃金鱼 | 是 |
| `vault` | 打爆桶 | 是 |
| `egg` | 砸金蛋 | 是 |
| `bonus` | 金蟾鱼池 | 是 |
| `pick` | 结尾转盘，配 `finale.pick` 写一星转到哪个（上面几种之一） | 是 |

其他可选：`finale.ladder = {"steps": [1.5, 2, 2.5, 3, 4, 5, 6, 8, 10], "base": 120}` 是结尾前的倍数跑道（兵够几格就点亮几格）；`finale.rbDiv` 改彩虹滚轮第一格的容量。

## 保存检查

导入、导出前都要过，不过不能导入也不能导出。每个问题都会写清是第几项、什么问题。

1. 有 `code`、`title`，`ch` 在 0～3。
2. `run.startN` 是 1～999 的整数；站桩关要有 `run.drift`。
3. 序列里每一项都是认识的积木，参数都填了、在范围内（如怪潮只数 1～200）。
4. 至少有一扇门；每排门 2～3 扇；门的值写法要对（见上表）。
5. 引用的资源要存在：鱼的名字、技能、桶的种类、Boss 模型、结尾种类、结尾转盘的结果。
6. 有剧本金额（`coins`）的关：必须是大关二起，结尾必须是能出金币的那几种。
7. 改的是 13 关之一时：这关的定格教学引用的第几扇门、第几个陷阱必须还在（比如删掉了门，教学还指着第 4 扇，就不过）。

## 全局参数

全局数值单独一份 JSON，所有关共用：

```json
{ "format": "gatefish-tune/1", "values": { "speed": 8.5, "stake": 500, "exchange": 100, "volleys": 16 } }
```

每个参数的名字、demo 的值、范围、什么时候生效、在哪里起作用，见 `src/edit/params.js`（调参台「全局」页就是按它画的）。导入时会检查名字认不认识、值在不在范围内。

调参台「导入导出」里还有「复制全部改动」，格式是 `{"format": "gatefish-edits/1", "tune": {...}, "levels": [...], "custom": [...]}`，可以整包带到另一台电脑。

## 完整例子

第 4 关（2-1 打怪掉金币），和 demo 里一模一样：

```json
{
  "format": "gatefish-level/1", "code": "2-1", "ch": 1, "title": "打怪掉金币",
  "learn": "怪头上写着倍数：打死按「倍数 × 炮倍 500」掉金币；结尾的彩虹滚轮，兵掉进 ×N 格每个兵赔 N 份",
  "hint": "怪身上写着倍数，打死就掉金币；打完 Boss 跑上彩虹滚轮，兵越多掉进的格子倍数越大",
  "teachKills": true,
  "run": { "startN": 8, "seq": [
    ["g", "+10", "x2", {"post": true}], ["w", 4, 6], ["roll", "gun", 1, 120, "C"], ["g", "+100", "x2"], ["cage", 10, 30, "C"],
    ["w", 6, 8], ["g", "x2", "+200"], ["w", 8, 10], ["roll2", ["shield", 1, 450], ["men", 40, 450]],
    ["g", "+400", "x2", {"post": true}], ["w", 8, 12, {"brute": 1}]
  ] },
  "finale": { "boss": { "hp": 2000, "name": "机甲", "model": "mech", "bite": 4, "sec": 7, "slam": 2.6, "m": 150 }, "after": "rainbow" },
  "coins": 700000, "par": 1800
}
```

更多例子和用 AI 出关的流程见 `docs/出关提示词.md`。
