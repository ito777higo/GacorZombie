# V4 工程交接

纯静态网页：HTML/CSS、原生 ES modules、固定 CDN Three.js 0.160.0、已随包提供的 Spine runtime/GLB。无需 npm 安装或构建。本地启动见 README。发布包可用任意静态 HTTP 服务承载，不能直接双击 index.html 代替 HTTP 模块加载。

主流程：3D 公路地图 → 选择目的地 → 自动射击与左右移动 → 停靠主任务地点 → 搜救 → 可选搜索/提前接应 → 继续深入时战斗与大怪 → 2.2 秒护送上车 → 归队报告 → 仓库/装备/下一站。

`journey.js` 的 `story.pois` 是地点定义，`run.seq` 的 `['poi',id]` 负责布置。RunSim 创建真实守门感染者；到地点切换 `search`，使用原 `updateZombies/fire/updateBullets`。requestSearch 不要求感染者清零，自动记录 forced 分支，决定搜索时间与追击。警报生成的感染者也进入同一模拟和表现，不是视觉假人。

Journey 控制器记录本局 bag/people；居民独立于 squad.N。装备在 begin 时仅对当前 squad 应用一次；每局新建 squad，避免累乘。gear 购买永久记在 save.journey.gear，下一局加载；包扎不消耗居民。

`secureCargo` 根据 run.id 防重复结算。成功后：可交易物品进 stash，任务/纪念物记 journal，居民按关卡去重；酬金由控制器加钱包。失败无任务酬金，也无物资保底。随身物资估值不自动进入钱包，出售才能到账。无出场门票或开枪金币消耗。背包不跨局。

保存键 `zombie-gold-journey-v4`；编辑器 `zombie-gold-journey-edit-v4`；统计 `zombie-gold-journey-playtest-v4`。存档只在本浏览器同源；端口变化视为另一个来源。主存档保留 cleared、next、wallet、journey（stash/gear/rescued/journal/receipts/runs）及设置。没有在线服务或跨端恢复。

主程序沿用 Game、RunView、FX、audio、haptics。原 campaign/rules.js 未改，旧捕鱼、奖金和关尾模块仍保留在源码中供未来参考，V4 无正常入口。宿主 bridge 仍是旧接口，本 demo 无宿主服务时完全本地运行，不能把本地金币当成服务器可信账本。

美术模块 journeyart 提供同一套地标、门闩、居民；journeyworld 提供五组地面、天色与路边物体，更新开门、居民移动和发射波纹；mapview 提供 3D 路线。UI 的 placeMap 会在 resize 后重新投影节点。地图只用浮动地标标签与一个出发卡片，没有全屏关卡文字目录。

V4.1 配乐改为现成参考曲 Lightless Dawn（Kevin MacLeod），截取原曲约 32–112 秒的 MPEG 帧，80 秒循环，未生成音乐。MUSIC_LICENSE.txt 保存来源、CC BY 4.0 署名及剪辑说明，并随包提供。原 10.23 音乐仍保留在工程中。桌面测试核验音频实际解码、播放与输出，以及振动调用。

V4.1 车门故障来自控制器每帧比较模板与序列化后的 innerHTML，空属性格式不同导致按钮每帧被重建，真实 pointerdown/pointerup 无法落在同一节点。现在只在换地点时创建按钮，帧更新仅修改文本、disabled 和进度。随身包按钮也修正同类重建。浏览器回归必须使用真实鼠标按压并跨越多帧，不能只直接调用 requestSearch。地图左上实验室恢复实际 overlay 节点及全部解锁功能，设置沿用当前存档键。

验收：`sh tests/run.sh`；浏览器真实五关与边界记录见上一级 verification/zombiegold-v4。保留原模拟、演员、存档回归；V3 专属 extraction 测试移到 tests/archive，本版用 journey.test.js。调参台、旧实验室和宿主接入不是本次完整回归范围。

打包：`python3 tools/build_release.py 4.1-interaction-fix`。发布包只含运行文件、必要素材与试玩说明；完整工程及文档保留在本目录。暂依赖 CDN/字体，不是离线包。zip 独立解压后也需 HTTP 启动。所有截图和自动验关均用独立临时浏览器，没有污染用户当前存档。
