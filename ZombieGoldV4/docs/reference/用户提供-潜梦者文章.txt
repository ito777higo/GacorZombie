Image
为什么这么多大佬看好？


文/严锦彦
大概半年以前，奥秘游戏的创始人徐奥林跟我说，他们打算用UE5做点不一样的尝试。
当时听到后，我一下就来了兴趣。一方面，奥秘本身就充满了噱头。他们最早是做密室逃脱，做解谜书的，转型游戏领域后，不仅获得了米哈游投资，还连着出了《山河旅探》《我在地府打麻将》两款好评如潮的产品。
Image
Image
在好游快爆等手游平台也保持着高分
另一方面，他们之前两款产品是AVG和玩法型肉鸽，主要靠点子取胜，这次一下上到UE5，他们想做什么着实让人好奇。
昨天，这个神秘面纱终于揭开了。他们的自研新品《潜梦者》发布了首曝PV，据介绍，这会是一款多人合作类型的搜躲撤产品，玩家要潜入梦境，挖掘做梦者内心深处的记忆。
Image
比起之前的名不见经传，这次《潜梦者》一上来就获得了不少大佬的肯定。比如这个项目的投资方和发行方均为Pilot games——前沐瞳CEO袁菁的创业公司（旗下有基金业务Pilot Game Ventures和发行业务)。徐奥林还说，他们这次立项过程中，米哈游总裁大伟哥也给予了不少帮助。
所以，《潜梦者》到底是一款什么样的产品，为什么大家都会看好它？我前阵子和奥秘游戏聊了聊。


01

从头脑发热，到科学决策


《潜梦者》的立项过程，和过去奥秘游戏的立项完全不同。
徐奥林跟我说，他们之前做项目，多少有点头脑发热，冲动大于理性。
比如做《山河旅探》是因为在解谜书上有点子无法实现，但扔了又觉得可惜，于是便将其做成了电子游戏；
做《我在地府打麻将》，则是因为外界都给奥秘打标签，认为他们人如其名，只会做推理、悬疑类产品，徐奥林不服，这才让他们叛逆了一次，撕掉标签。
最后，这两款产品虽然都收获了好评如潮的玩家认可，但难受的是，一算账，团队发现他们竟然是微微亏钱的。
Image
《山河旅探》被玩家称为近年的国产神作
“在游戏行业，选择大于努力，”徐奥林跟我说，“游戏是一个作品化和工业化兼具的产品形态，我们复盘后觉得，新项目还是需要更科学的立项过程，要做市场调研，结合团队特性，去精挑细选。”
在这次立项过程中，米哈游的大伟哥也给了他们不少建议，甚至还专门安排了几位专业的同学给他们做立项指导。
渐渐地，《潜梦者》的几个方向逐渐清晰了。
首先是从Unity迁移至UE5引擎，这是技术栈的升级。
徐奥林认为，在Unity的开发模式下，中小团队自身需要补全非常多短板，他们能明显察觉到团队的瓶颈。但UE本身集成了大量游戏开发思维，背后有着充足的案例和资源库能支撑团队开发。
“Unity像是技术团队做的，而UE更像是做游戏的团队做的。对于我们这种半路出家的团队来说，用了UE，就感觉进了一个巨大的图书馆，它能更好地帮助我们学习和理解游戏开发架构。”
此外，大伟哥也给徐奥林提了不少建议。比如当时《33号远征队》正大火，他们聊起来，徐奥林才知道这游戏真的是只靠33个人做出来的，原来在UE技术栈的加持下，成本可以控制到这么极致。聊到这里，大伟哥也鼓励他们可以去试试。这也是他们考虑更换技术栈的重要原因。
Image
其次是市场赛道的选择。之前，团队做的都是单机，传播性较弱，哪怕《山河旅探》的口碑和声量在AVG里已经算很好了，但依然很难出圈，更何况很多人可能云完了剧情，就不会再买了。
那什么类型的产品有着较强的传播性呢？恰好，团队近年来喜欢玩多人联机游戏，这个品类不仅适合传播，也与团队过去做密室的经验相契合。
于是，他们便从《致命公司》等产品上获取灵感，选定了搜打撤的方向，在他们看来，这是一个更先进的，具备高复玩性的关卡结构；随后又从团队特性出发，决定尽量少做战斗、避开短板，因此他们也戏称自己是“搜躲撤”。
Image
具体来说，游戏的核心玩法机制是“抓取”。为了让我更好理解，徐奥林拿《塞尔达传说：王国之泪》的“究极手”来举例，你在《潜梦者》中可以抓取物品、同伴，把他们放置到任意位置，以此实现解谜。
从PV中我们能看到，很多时候玩家需要通过“抓取”搭起人桥，或者接力，帮助同伴跃过悬崖；又或者，玩家可以把不同的物品组合起来，形成一个跳板，让你去到新的地方。
Image
Image
在徐奥林的设计思路里，这种解谜应该是大道至简，充满多元解法的。因为“抓取”是一个可以让玩家充分发挥想象力的机制，只要他们能为玩家的脑洞提供足够多的舞台，那么游戏就会变得有趣起来。
“拿我们过去做密室举例，玩家要破解一个密码锁，不一定非要去和机关交互找到密码，他们也可以用暴力手段把锁砸开，我们应该尊重这种行为。”
听到这里，我觉得这是不是说得有点太简单了，毕竟涌现式设计可没那么好做。徐奥林也说，这确实很难总结出一套方法论，很多时候就是靠玩家视角的直觉，“重要的是开发者的理念，我们不能想着怎么教玩家玩游戏。”
当然，这一理念也有具体的实现方式。徐奥林说，团队的一个核心设计思路，是让关卡中各个环节的逻辑解耦，给玩家留下自行寻找解法、甚至跳过部分环节的空间，避免玩家必须猜中开发者的思路才能过关。
具体来说，就是避免把流程写成“A→B→C→D”这样环环相扣的硬性依赖：只有完成A，B才会开启，随后才能进入C、D。团队希望让每个环节各自独立，不通过程序中预设的完成状态彼此绑定，而是通过距离、高度差、温度、水位、浮力等更直观的环境条件与物理机制，形成挑战和限制。
相应地，解开机关的“钥匙”也应来自游戏中通用的底层机制。例如，机关响应的是水、火、风的作用，是足够的冲量，或是符合条件的形状，而非某件被程序指定的唯一道具。只要玩家利用这些规则达成了条件，无论采用什么方法，都可以推动机关；如果找到了绕过障碍的办法，也可以直接继续前进。
再举个例子。PV中展现了一个扇贝怪，它会把靠近的人给“吃”进去。玩家一开始会躲避它，但后面可能会想着，能不能把怪物引到这里，让它吃掉怪物？再者，扇贝怪过一段时间就会重新打开贝壳，那玩家站在上面，是不是可以借力跳到更高的地方，又或者把物品放在上面弹射出去？也就是说，同样一个设计，并不一定只服务于一个目的，它可以是多个谜题的解。
Image
而在解谜之外，“抓取”也可以让玩家之间产生更多交互。毕竟，玩多人合作游戏，很多时候大家都会互相指点，你抓的时机、放置物品的位置对不对，都决定了玩家小队烧不烧心，它能有效带动游戏氛围。再进一步，能够互相抓取玩家，其实也给“互坑”提供了空间，这也是多人合作游戏需要的关键。
而在确定了玩法后，剩下的就是题材了，这也是团队思考了最久的东西。
徐奥林觉得，UE5虽然能为团队提供很好的开发架构，但在资产方面给予了他们很大的挑战。毕竟他们不像黑神话或影之刃，有能力挑战大体量项目。作为不到30人的中小团队，想要打磨好UE的3D资产，光靠他们实在力不从心，如果找外包的话，费用又承担不起。
所以他想，能不能找到一个合适的世界观题材，把UE5本身的优质素材库给串联、复用起来，做出玩家常见视野之外的组合和呈现。为此，他们在几个月里想了不少题材方向，但每一个题材感觉都有点将就，团队始终没有足够的创作冲动。
在这段时间里，团队也在经历一阵迷茫期。由于这次立项变得更加谨慎，徐奥林和别人聊得越多，听到的声音越多，也越感迷茫。有人说，他们就应该做非常轻量级，能快速交付的产品，像《我在地府打麻将》那样，完全以玩法取胜；也有人说，他们应该高举高打，吃下UE5技术升级的红利；还有人劝他们，不要步子太大扯着蛋。
Image
那段时间，徐奥林常常会做噩梦。直到一次梦醒，他突然想到，何不把这些奇奇怪怪的梦境，做成游戏呢？一方面，梦境在空间方面能有不少设计，能用上他们过去在密室方面的经验，同时团队也对这个题材有表达欲；另一方面，梦境是不按常理出牌的，可以减轻他们在资产方面的压力。
Image
也是在这时，他们和pilot团队聊起这个方向，对方给予了不少肯定。徐奥林觉得，之前大家聊方向，总会提出不少问题，但这次的反馈十分积极，于是他们有了更多的信心，双方也一拍即合，决定一起合作。
就这样，《潜梦者》在2025年的最后一晚，元旦前夕，确定了梦境题材的方向。



02

把梦境做透


如果要用一个词去概括《潜梦者》的创新设计，那么或许是“空间”。我们可以从三个方面去理解。
首先是空间变化带给玩家的游玩反馈。
从PV中可以看到，游戏依托梦境，塑造了不少具有纵深感、梦核感的奇观，比如地铁是从上往下开的，站台像万花筒般层层推进，这在视觉上就会与其他产品拉开差距，勾起玩家在地图中的探索欲。
Image
而在具体游玩过程中，团队还设计了大量的空间变化。比如当玩家冲过一道屏障，亦或是掉落一个悬崖后，会来到一个新的巨大空间；打开一扇门，玩家会通向完全崭新的空间，回过头时，又能从门中看到来时的场景。
Image
徐奥林说，团队为了塑造出梦境般的感受，把不同空间都折叠进了一个空间里。这种无缝切换的场景变化背后，团队花了不少时间去做技术调研和学习。
其次，塑造出了具有梦境感的空间后，团队也在设计能与之相匹的多人玩法。
徐奥林给我展示了一个巨大的莫比乌斯环场景，不同玩家会站在莫比乌斯环的两面，像是互相对立一样，随后互相配合过关。
Image
PV中同样展现了类似的设计。在一个上下颠倒对立的经典场景中，几名玩家需要通过抓取，传递物品，以此解决难题。如果再联系到空间的无缝切换，或许游戏还能像《传送门》那样，依靠空间机制，设计出更复杂的合作解谜。
Image
另外，徐奥林还给我展示了一个与空间联系得更紧密的合作玩法。在一个场景中，空间会随着玩家的移动而实时变化，玩家想要通过这个场景，或许需要一名玩家先移动到某个位置，等空间变化后，再让另一名玩家移动。虽然这听起来可能没有特别创新，但如果联系上实时变化的巨大的3D场景，它带给人的震撼感还是很强的。
最后是空间变化带来的叙事体验。
奥秘游戏的官网上，其实就展现了一小段例子。玩家会探索一个公司白领的梦境，空间场景从逼仄、曲折，逐渐过渡到更大、更开阔，但无论场景怎么变，不变的都是电脑、工位，以及干不完活的打工人。
Image
PV中还出现了一个六面体建筑，每一面都是一扇门，透过门，你能看到婴儿床、玩具房、工位、病床，玩家可以穿梭进去，感受做梦者的一生。
Image
徐奥林跟我说，在搭建《潜梦者》的世界观架构时，团队参考了大量心理学的专业书籍，其中荣格的精神分析学是世界观的一大来源。
比如，玩家会和伙伴一起进入别人的内心世界，挖掘做梦者内心深处的秘密，这是搜打撤的框架；而在大框架里，玩家会逐渐从表层梦境，进入到深层梦境，最后进入到集体无意识的领域。
又比如，在梦境中，玩家会遇到许多危险，有的怪物来自于做梦者的思想，这是因为触发了他们的心理防御机制；但有时这些怪物又来自于玩家、来自于潜梦者本身。最后玩家被怪物吃掉，其实是触发了所谓的人格混同。
Image
徐奥林说，奥秘并不是一个执着于一定要讲故事的团队，否则也不会去做《我在地府打麻将》了。之所以想要在《潜梦者》中做好叙事，是因为他们认为这是自洽的过程。
“如果我们不做好设定，不去解析为什么这个梦境是这样的，那么团队自己在创作过程中也会就某个设计不断发问，地编、美术、策划都会问为什么我要这样做。”
现在，徐奥林经常跟团队讲，梦是不讲逻辑的，理论上它可以天马行空，在画面表现力层面，它可以有极大的张力，可以上九天揽月；但梦的底层又是有逻辑的，在玩家最终游历完后，还是会发出人生三问，“我是谁、我在哪、我来干嘛，要到哪里去”。因此，只有把做梦者的成长经历和人物画像都设计好了，真正做好叙事，才能把梦境的题材做透，把潜梦的感觉传递给玩家。
Image
pilot也认为，《潜梦者》和市面上很多多人合作游戏不同的地方是，它并不只是玩家之间的快乐小甜水，在互动玩法之外，他们还在尝试通过叙事，带给玩家更多触动——某种程度上有点像是《双人成行》。这样玩家回忆起来，除了朋友间的快乐以外，可能还会有不一样的收获。



03

结语


在徐奥林看来，现在的多人合作游戏能够大火，一个很重要的关键词是旅程感，这也是《潜梦者》很早就确定下来的核心。
“好几个游戏都给了我启发和信心，无论是《peak》还是《bigwalk》，它们给玩家最强的心流，都是让玩家一同踏上一个旅程，中间玩家会看到很多奇观、展开有趣的互动，就算操作失误了，大家也不会生气，而是开心大笑。你如果硬说《peak》的攀爬玩法本身，一定程度上可能也没那么有趣。所以抛开一切乱七八糟的设计，我们最想做的只有一件事：让你跟几个好朋友，一起经历一场梦中的旅行。”
目前，《潜梦者》刚刚首曝，距离正式发售还有一段时间。我也好奇，一家连续做出好产品的独游工作室，开始尝试更科学地创作和开发之后，是否还能延续之前的成功，又或者说能否获得更大的商业成功。
