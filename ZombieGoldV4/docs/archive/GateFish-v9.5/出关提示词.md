# 用 AI 出关：表单模板和提示词

编辑器功能二（出新关卡）的薄版本：不做界面，策划填一张表单、写几句描述，交给 Claude 或 Codex 生成一份关卡 JSON，粘进调参台导入，自动验关，再微调。

## 流程

1. 按下面的「表单」填好这关，再用几句话写节奏和感觉。
2. 把「提示词」整段、`docs/关卡配置格式.md` 全文、填好的表单一起发给 Claude / Codex。
3. 拿到 JSON，打开 demo 的调参台（链接后面加 `#edit`），在「导入导出」页粘进去，点「检查并导入」。保存检查没过会逐条列出第几项、什么问题，改了再导。
4. 回到「本关」页点「重开本关」试玩；到「验关」页选「本关」，三种走法各跑 20 次。
5. 看验关表：过关率、带回兵数、金币和剧本差多少、每扇门前的兵数。在「本关」页直接改数，改完点那一项的 ▶ 从那里重开。
6. 满意了在「导入导出」页「复制本关 JSON」，交出去。

## 表单

```
大关：（大关一 数字门 / 大关二 兵变金币 / 大关三 大鱼爆分 / 大关四 捕鱼技能）
关卡编号和名字：（编号别和 13 关重复，如 T-1）
这关要教什么：（一件事）
可用积木：（只能从「关卡配置格式」里选，如 门、怪潮、二选一滚桶）
跑道长度：（几项积木，一项约 3 秒；或一关多少秒）
站桩还是跑关：
难度：（一般走法过关率目标；兵会不会掉一大半；乱走能不能过）
Boss：（模型、倍数，或不要 Boss）
结尾：（彩虹滚轮 / 金砖墙 / 黄金雪怪 / 鱼跃金鱼 / 打爆桶 / 砸金蛋 / 金蟾鱼池 / 结尾转盘 / 兑换门 / 直接结算）
剧本金额：（大关二起才有，如 700K）

描述：
（几句话写这关的节奏和感觉，例如「前半段一直涨兵，中段一排桶加两侧扑出的怪，×3 门后面紧跟精英」）
```

## 提示词

```
你是《一路爆金币》的关卡策划助手。游戏是 Last War 式的数字门跑酷：队伍自动往前跑、自动射箭，玩家左右拖动选门涨兵、打怪、打桶、躲陷阱，最后打 Boss、进结尾惊喜换金币。

请按我附上的「关卡配置格式」，根据表单和描述出一关。要求：
1. 只输出一个 JSON 对象，不要解释，不要 Markdown 代码块以外的文字。
2. 只用表单里「可用积木」列出的积木，再加门（g）。
3. 门的数要让答案随兵数变：兵少时加法好、兵多时乘法好。金柱（post）只放在少数门上。×3 以上的门后面紧跟一波怪或滚桶。
4. 一关要有高、低、再高的起伏：涨一段兵，给一次真的会掉兵的压力，再给翻回来的机会。
5. 数量级参照现有关卡（下面的参考表和两个例子），不要差太远：开局兵数、怪潮的只数和血量、桶要打几下、Boss 血量和倍数。
6. 有剧本金额时：大关二起才能有；结尾必须是能出金币的那几种；par 填「一般走法带到结尾的兵数」的估计（参考同大关的关）。
7. 输出前按「保存检查」7 条自己查一遍。

[附：docs/关卡配置格式.md 全文]
[附：填好的表单和描述]
```

## 数量级参考（demo v9.5 的 13 关）

| 大关 | 开局兵 | 怪潮（只数 / 血量） | 桶要打几下 | Boss 血量 / 倍数 | 剧本金额 | 一般兵数 par |
|---|---|---|---|---|---|---|
| 大关一 | 3～10 | 2～16 / 3～18 | 60～130 | 1600～5000 / 无金币 | 无 | — |
| 大关二 | 8～12 | 4～22 / 6～40（站桩关血量更高） | 30～450 | 2000～3000 / ×150～×180 | 580K～780K | 380～1800（2-3 有倍数跑道：65000） |
| 大关三 | 14～16 | 10～34 / 12～60 | 3～90 | 6000～7000 / ×225～×300 | 540K～760K | 220～2400 |
| 大关四 | 12～14 | 8～16 / 8～16；纵队 4～5 路 × 6～8 只 / 20～30 | 8～40 | 4500～9000 / ×300～×375 | 600K～640K | 150～2500 |

大关二起，开局兵、加兵门、加兵桶、兵雨都会再 × 兵力系数（现在 ×2）；怪潮的只数和血量会再 × 1.5 和 × 1.15。

表单：

```

Boss：巨尸王，大体型，×180

## 例子三：用这套流程真出的「测试关」（v9.5 验证）

表单：

```
大关：大关二 兵变金币
关卡编号和名字：T-1 测试关
这关要教什么：站桩关里的滚桶：会滚过来压人，打爆拿道具
可用积木：门（含可开枪的扣兵门）、怪潮（含精英、每只扣 2 兵）、滚桶、二选一滚桶
跑道长度：13 项
站桩还是跑关：站桩，飘过来的速度 6.5
难度：一般走法能过，乱走有可能输
Boss：巨尸王，大体型，×180
结尾：彩虹滚轮
剧本金额：700K

描述：开局给一扇 ×2 和一个滚过来的换弩桶；中段一个二选一滚桶（加兵 / 护盾），一排三扇可开枪的扣兵门；后半段怪潮越来越厚，再给一次治疗 / 换弩的二选一；最后一扇金柱 +120 / ×2 收尾。

| 走法 | 过关率 | 带回兵 | 金币 | 和剧本差 | 打怪+Boss | 结尾 |
|---|---|---|---|---|---|---|

每扇门前的平均兵数（第二轮）：最优 20 / 89 / 194 / 436，一般 20 / 86 / 152 / 393，乱走 20 / 58 / 63 / 148。最优和一般都落在剧本 ±10% 以内，乱走四次里有一次会输，符合表单。
