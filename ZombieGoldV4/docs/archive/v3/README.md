# 末日突围 · V3 撤离体验版

从玩家体验出发，把跑关、Boss 和关尾连接成一次完整的救援行动。此前两版保留，本版独立运行。

## 启动

在本目录运行：

```sh
python3 -m http.server 8018 --bind 127.0.0.1
```

打开 http://127.0.0.1:8018/ 。无需 npm 或构建；Three.js 和字体仍需联网。鼠标/触屏左右拖动，或 ←→ / A D，队伍自动射击。数字门扩兵、武器和 Boss 躲避保留。

## 这版的体验

- 所有 13 关统一为：行动选择 → 突围 → Boss（部分关卡）→ 守住撤离区 → 撤离报告。
- 撤离战 9～12 秒：守住追兵、抢救补给、靠绿色信标加快接应。红区预告扑击，向另一侧移动可以避免损失。
- 不再在主流程出现彩虹滚轮、金砖墙、金蛋、转盘、翻牌和僵尸捕鱼。鱼牌/飞鱼目标改为增援和侧路尸潮。
- 金币在战后按明确规则清点；战斗中强调人员和火力，撤离报告先报人、救援和零件，再展开酬金明细。
- 地图改为连续行动路线，移除主游戏大厅 LV4 拦截和捕鱼奖励。狙击形式的捕鱼等用户后续说明，本版不实现。
- 避难所设施、费用、居民与零件规则沿用 V2。医疗可用于新增撤离战；没有新增建设系统。
- 背景音乐使用用户指定的 10.23/kartrider_village01_loop_60s.mp3，作为 assets/audio/bgm_short_intro.mp3 从 0 秒播放，不继续用旧 AAC。

## 数值与验证

前三关不产金币。其他关卡保留途中清敌/回收收入，撤离另给：
20,000×(章节序号+1) 的行动奖励 + 100×实际撤离队员 + 5,000×撤离战回收箱数。
原来的关尾剧本补分、宝箱 ×1,419 及转盘倍数退出本版流程，收入不与前版等量。

8 组 749 项检查通过。Chrome 实跑 13/13 撤离成功；另验三种撤离任务、红区输入躲避、失败重试、调参台恢复存档、地图、手机布局和音乐加载。证据在上级 verification/zombiegold-v3/。

存档独立：zombie-gold-experience-v3；调参台、统计也使用 V3 键，不迁移或覆盖 V1/V2。只保存资源进度，不保存关卡现场。
