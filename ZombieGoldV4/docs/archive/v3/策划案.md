# V3：玩家这一局到底在做什么

原来的体验断点是：玩家一路救人、躲尸潮、打 Boss，刚建立的生存目标，在关尾变成彩虹滚轮、金砖墙、砸金蛋或翻牌。它们单独可以有爽感，但与“把人带出来”不是同一个目标。只是改名和压暗场景，无法解决这种断裂。

本版的统一目标是：带着还活着的人坚持到接应抵达。数字门和武器仍提供即时成长；结尾继续使用已经学会的左右移动和自动射击，不再突然切换抽奖或捕鱼。金币仍存在，先让玩家看懂撤离，再清点奖励。

## 一局的节奏

行动简报 → 选营救/搜刮/撤离 → 跑关与武器成长 → Boss → 最后 9～12 秒撤离战 → 撤离报告 → 下一段路线。

撤离目标轮换，但操作一致：
- 守住撤离区：正面尸潮、较强感染体、红区扑击，先保住队伍。
- 抢救补给：左右射击三只军用补给箱，能拿多少拿多少，拿不到不挡通关。
- 信号接应：靠近绿圈可将接应速度提高到 1.55 倍；红区出现时离开，形成“加快接应还是先躲”的短时取舍。

每 3.4 秒一波实际敌人；扑击有 1.6 秒预告。站在范围内损失当前队伍约 12%，避开不扣，原护盾可挡。不会用自动扣兵假扮战斗；火力、敌人碰撞、死亡与急救都实际参与。队伍为零失败；活到接应到达才成功。先按这一强度试玩，不声称已完成难度平衡。

## 奖励的意义

战斗中不再给每个僵尸挂赔率，不显示“兵值多少钱”，不反复飘出巨额金币，也不教玩家炮倍。击杀的底层收入暂时保留，作为清理威胁的酬金，集中在报告里说明。

前三关继续不产金币；之后撤离成功给：20,000×(章节下标+1) + 实际撤离人数×100 + 补给箱×5,000。没有关尾补到剧本金额、随机开倍或宝箱翻牌。失败保留已记入的途中收入，避难所居民/零件仍按 V2 原规则处理。

报告首先展示撤离队员、清除威胁、救援居民和零件；金币收入折叠展示并列明来源。保留“这局赚到了”的感觉，减少“人只是拿去消耗的筹码”的表达。

## 地图与未做的分支

第四章随前关进度自然解锁，不要求先去另一个捕鱼系统升大厅 LV4。地图显示 13 个连续行动，通关后可重玩。旧捕鱼入口、场次选择、免费子弹卡和鱼雷首通奖励退出本版流程。用户已说明未来是另一种狙击形式的捕鱼；这里不预设怎么接、不做替代设计。

避难所先保留 V2 的行动选择、三级设施、居民、零件和急救包经济。只将医疗支援接入新撤离阶段，不追加饥饿、感染或建设分支。

## 声画取舍

保留白天和清晰的射击辨识，不把末日简单等同于黑暗。补给换成军用箱，接应区加标线、绿信标和红色扑击区；撤离报告用现场简报风格，去掉大奖放射线、庆典与赌场结算卡。

音乐按用户指定使用 10.23/kartrider_village01_loop_60s.mp3，保持其现成剪辑，从 0 秒开始，60 秒循环。没有叠加前奏，也没有用新合成底音代替用户曲子。浏览器 AudioContext running、加载/播放成功、实际 URL、循环起止均已记录。

## 本轮要用户判断的事

跑完 Boss 后的最后一段是否有“等接应”的紧张感；三种任务是否能一眼看懂；红区是否易躲；金币移到战后是否还保留收益感；9～12 秒撤离是否让早期关卡变长。已有角色仍偏卡通且风格有混搭，本轮解决体验逻辑的连接，后续可按具体画面继续换演员或做场景。
