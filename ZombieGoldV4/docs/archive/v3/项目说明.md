# V3 撤离体验版

用户反馈：原玩法的晴朗、轻快与庆典式小玩法和末日打僵尸不一致，希望从玩家体验改一版；避难所暂不扩展；未来捕鱼采用另一种狙击形式，须等用户另行说明。追加要求：使用 10.23 子目录的短前奏音乐。

本版从 ZombieGoldV2 复制到独立目录，不覆盖前两版和 inbox 原件，不推送 GitHub。启动端口 8018，存档独立使用 zombie-gold-experience-v3。

真实实现：13 关统一战斗撤离；守阵、补给、信标三种撤离目标；红区扑击和躲避；军用补给箱、接应车辆和撤离报告；连续路线图；旧关尾和捕鱼入口退出主流程；指定 MP3 已接入并由浏览器验证播放。避难所经济和设施不扩展。

这是一次体验整合，不是重新制作全套美术。沿用已有 Spine 和卡通战斗表现，保留清晰的数字门与射击反馈；不把画面一味变黑。关卡数字门和武器教学保留，路面和 Boss 的主要配置沿用。现有素材的部分夸张变异体仍有风格混杂，下一轮可针对具体角色换演员。

规则在 content/experience.js 与 sim/extraction.js；画面在 view/extractionview.js；新路线与结果在 ui/missionui.js。旧捕鱼代码与旧开奖模块仍保留供历史参考，但没有进入本版主流程，startFishing 也已拦截。没有实现狙击玩法，不推断用户后续的概率或经济设计。

测试结果、实际截图、音频 SHA-256、解压包验证见上级 verification/zombiegold-v3。浏览器验收用独立临时存档，正常试玩来源固定可继续进度。更好玩的结论需要用户试玩评判，自动驾驶只证明流程和规则。
