# 效果参数对照表

这份表把 demo（three.js 网页版）里每条体验细节的具体做法和数值列出来，给 Cocos 3D 前端复刻手感时对照用。
表里的数都是 demo 现在的起点，不是定稿。写成 `TUNE.xxx`、`cam.xxx`、`mix.xxx` 的，都能在调参台「全局」页直接改（网址后面加 `#edit` 打开，本地也可以用 `?edit`）。
每条"为什么"写在需求文档「体验细节：做法和原因」和「H5 前端 · 震动反馈」里，这里不再重复。
代码位置只写文件和函数名，不写行号。代码和需求对不上的地方，表里按代码写，最后一节统一列出来。

**看表前先说几个约定**

- 长度用世界单位。路宽 11.2（半宽 `ROAD_HW` = 5.6），跑关速度 `TUNE.speed` = 8.5 单位/秒，所以 8.5 单位大约是 1 秒的路。
- "追随系数 k"：每帧做 `当前 += (目标 − 当前) × (1 − e^(−k·dt))`。k = 3 时约 0.33 秒走完 63%，约 1 秒基本到位。demo 里统一用 `damp()`（`src/sim/util.js`）。
- 慢动作 `Game.slowmo(秒, 倍速)`（`src/game.js`）：时长按真实时间算，再乘 `TUNE.slowmo`（1，全局页）；这段时间里游戏按"倍速"走，结束后以追随系数 8 回到 1 倍（约 0.3 秒恢复）。
- 震屏 `world.shake = s`（`src/view/world.js World.update()`）：s 按游戏时间每秒减 1。每帧镜头位置在 xyz 上各随机偏移 ±s²×3 单位，所以 0.9 的震屏开头很猛、衰减很快，0.3 只是轻轻一抖。
- 飘字 `UI.float()`（`src/ui/ui.js`）：出现时从 1.8×pop 倍缩回 1 倍，用时 0.16 秒；往上飘的速度 vy 像素/秒，每秒衰减到 e^−2.2；寿命最后 30% 淡出。
- 横幅 `UI.banner()`（`src/ui/ui.js` + `styles.css .banner`）：普通横幅在屏幕 34% 高处，字号 44px，用 0.5 秒带回弹的动画从 2.2 倍缩进来，停 dur 秒，再用 0.3 秒淡出。

|---|---|
| `gateGood` | 4 个 bell，每个隔 0.05 秒，起音随兵数升高（见第 1 节），外加一段 0.22 秒、800→2400Hz 的上扫噪声 |
| `gateBad` | 三角波从 G4 滑到 C4（0.26 秒），加一个 150→70Hz 的正弦低音 |
| `coin` / `coinTick` | coin：两个 bell，相隔 0.045 秒，音高随连击升高，限频 35ms；coinTick：0.04 秒的轻正弦，限频 28ms |

| `cashout` | 8 个 bell 顺着音阶往上爬，每个隔 0.05 秒 |
| `hurt` | 三角波 210→90Hz，加低通噪声，限频 70ms |
| `boss` | 70→45Hz 的长低音（0.9 秒），加 C2、G2 两个三角波和低通噪声，同时让音乐 duck 1.6 秒 |

## 需求文档和 demo 对不上的地方

1. **Boss 出场 / 砸地的震动**：需求写"三下，最后一下最重"。demo 的 `boss` 是 [30, 40, 70]，只有两下；砸地本身用的是 `boom` [60, 30, 90]。
2. **大倍数门**：需求按"×5 以上"写。demo 的大门判定是"过后 ≥ 过前 3 倍，并且多出 ≥30 个"。大门的震动 demo 里确实没有：`upgrade` 被同一帧的 `gateGood` 覆盖，实际就是 14ms。
3. **自动降画质**：需求是三步（先降分辨率、再关阴影、最后少画兵）。demo 只有两步，关阴影和少画兵在同一档；少画的是外圈的兵，不严格是后排。
4. **教学小标签**：需求写"停两秒"，demo 是 2.6 秒。
5. **爆分慢动作**：需求写 0.25～0.6 秒。demo 里金蟾和鱼池大鱼是 0.9 秒，大门是 0.35 秒。
6. **Boss 赢了到出结算**：需求写约 2 秒，demo 约 2.7 秒（2.4 秒进结算流程，再 0.3 秒弹卡）。
7. **音乐比音效低多少**：需求写 15～20 dB。demo 注释里写的实测约 12 dB（两条总线的增益差约 16 dB）。
8. **兵数是画面里最大的数字**：demo 的兵数牌是 26px，木桶的剩余次数是 30px，桶上的数更大。
9. **钱包旁冒 +N、金币多了合并成一个数跳**：demo 里没有，只有在怪死的地方合并成一个飘字，加上钱包数字往上滚。
10. **挑战关"每隔几关一个"**：demo 13 关里只有 3-2 一个。
11. **音效开关、震动开关"设置里能关"**：demo 没有音效开关按钮；震动开关和音乐开关都在实验室面板，不在正式设置里。
12. **被撞的震动间隔**：需求写至少 0.12 秒，demo 是 0.16 秒（更严，问题不大）。
13. 代码自己前后不一致（不影响效果，复刻时以代码为准）：
    - 调参台 `src/edit/params.js` 里说骑柱宽度和撞柱比例作用在 `runsim.js passGate()`，这个函数已经不存在，实际在 `RunSim.updateGates()`。
    - `FX.hit()` 的注释写"三支出一个效果"，实际概率是 0.38。
    - `RES_SLOTS` 的注释写"五个栏位"，实际是 6 个。
